B. API Gateway REST (api-gateway/src/server.js y api-gateway/test/server.test.js)
- Regla R4 corregida en POST /api/actas: en lugar de devolver HTTP 400 ante descuadre
  aritmético, el acta se registra en estado OBSERVADA con motivo ERROR_ARITMETICO
  y JEE competente asignado (jeeAsignado).
- Nuevos endpoints del flujo TO-BE implementados:
  * POST /api/actas/:tipo/:id/contabilizar (endoso ONPE AND JNE simulado).
  * POST /api/actas/:tipo/:id/observar (SUPERVISOR_COMPUTO).
  * POST /api/actas/:tipo/:id/ejemplar-jee (JEE_SECRETARIO + cotejo de hashes + R6).
  * POST /api/actas/:tipo/:id/resolver (JEE_MAGISTRADO / JNE_PLENO + R6).
  * POST /api/actas/:tipo/:id/recuento (JEE_MAGISTRADO + R6 + votosAnteriores R10).
  * POST /api/actas/:tipo/:id/constancia (PERSONERO + bloqueo tras proclamación R7).
  * POST /api/actas/:tipo/:id/nulidad (JEE_SECRETARIO / PERSONERO + plazo 3 días R7).
  * POST /api/proclamacion y GET /api/proclamaciones (bloqueo R9 + raíz de Merkle).
  * GET  /api/actas/buscar/:id (búsqueda por código sin requerir tipo de elección).
  * GET  /api/actas/:tipo/:id/constancia-evidencia (RF10: genera constancia criptográfica
    firmada con selloIntegridad SHA-256 para trámite ante el JEE).
  * POST /api/verify/votos (comparación de votos de copia física frente al ledger).
  * GET  /api/outbox, POST /api/outbox/enqueue, POST /api/outbox/flush (patrón Outbox RNF04).
  * GET  /api/openapi.json (documentación OpenAPI 3.0.3 según RNF10).
- Seguridad y control de API Gateway (RNF05): cabeceras X-Content-Type-Options /
  X-Frame-Options y limitación de tasa en memoria (HTTP 429).
- Soporte de votos IMPUGNADOS en el PDF generado por PDFKit y sincronización
  determinista de inicialización (ready / resetToInitial) para pruebas limpias.
- api-gateway/test/server.test.js: ampliado de 2 a 6 pruebas de integración cubriendo
